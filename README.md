# 다논풀무원 HR 시스템

풀무원 인턴 대상 근태, 식대, 휴가 관리를 위한 모바일 웹 HR 플랫폼입니다.

---

## 기술 스택

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Database**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth
- **Styling**: Tailwind CSS
- **State**: Zustand
- **Deploy**: Vercel

---

## 주요 기능

### 사용자

#### 출퇴근
- 출근 / 퇴근 버튼으로 당일 근태 기록
- 세션 기반 근무 추적 모드 지원 (여러 세션 분리 기록)
- 홈 화면에서 오늘 출퇴근 시각 및 주간 근무시간 확인

#### 근태 관리
- 주간 캘린더로 일별 근무시간 조회
- 팀원 캘린더 (같은 주에 누가 쉬는지 확인)
- 출퇴근 시각 수정 요청 기능
- 유형별 휴가 신청: 연차, 반차, 병가, 경조사, 면접, 시간 휴가
- 출장 신청 (목적지, 기간, 사유 입력)
- 신청 내역 상세 조회 및 처리 상태 확인

#### 초과근무
- 초과근무 기간 내 기대 근무시간 대비 실제 근무시간 조회
- 여러 기간이 배정된 경우 드롭다운으로 기간 선택 가능
- 주간 기준 / 기간 전체 기준 전환 조회
- 회사 휴일 및 주 근무일수 반영 자동 계산

#### 식대
- 영수증 촬영 및 OCR 자동 입력 (상호명, 메뉴, 금액)
- 주간 영수증 목록 및 승인 현황 확인
- 월 식대 한도 및 잔여 한도 표시
- 식대 양도 기능 (다른 직원에게 잔여 식대 이전)
- 식대 내역 전체 조회 (지급, 사용, 이전 내역)

#### 마이페이지
- 푸시 알림 설정
- 비밀번호 변경
- 문의하기 및 문의 내역 조회
- 계정 탈퇴

---

### 관리자

#### 직원 관리
- 전체 직원 목록 조회 및 오늘 출퇴근 상태 표시
- 직원 정보 수정: 이름, 부서, 직급, 연락처, 이메일
- 권한 설정: 직원 / 인사담당자 / 관리자
- 재직 상태 / 재택근무 / 세션 근무 추적 / 주 근무일수 설정
- 계정 삭제 (관련 데이터 일괄 삭제)

#### 근태 관리
- 전체 직원의 주간 출퇴근 시각 그리드 조회
- 관리자 직접 출퇴근 기록 수정
- 휴가 / 출장 신청 승인 및 반려
- 첨부파일 포함 휴가 신청 별도 관리

#### 초과근무 기간 관리
- 초과근무 기간 추가 / 수정 / 삭제
- 기간 생성 시 배정할 직원 체크박스 선택 (전체선택 / 전체해제)
- 배정 직원이 없는 경우 전체 직원 자동 적용
- 기간 생성 전 배정 겹침 사전 검증 (동일 직원이 겹치는 기간에 이미 배정된 경우 저장 불가)
- 기간 결과 카드에서 직원별 초과근무 현황 확인
- 3건 초과 시 페이지네이션

#### 회사 휴일 관리
- 회사 자체 휴일 등록 및 삭제
- 등록된 휴일은 초과근무 기대 시간 계산에서 제외

#### 식대 관리
- 월 식대 한도 및 일별 한도 설정
- 직원별 식대 사용 현황 조회
- 영수증 승인 / 반려 처리
- 직원 간 식대 이전 내역 조회

#### 문의 관리
- 직원 문의 목록 조회 및 처리 상태 관리

## 화면 구성

```
/               홈 (출퇴근)
/attendance     근태 캘린더
/meals          식대
/mypage         마이페이지

/admin                  직원 관리
/admin/attendance       근태 관리 (초과근무 기간 포함)
/admin/meals            식대 관리
/admin/inquiry          문의 관리
```
